## Summary

This PR adds the infrastructure and scripts to scrape, export, and seed all SAT practice questions from the Bloom Academy platform into the HomeSchool backend database.

## Changes

- **Model (app/models.py)**: Added `source_test_id` column to the `Question` table to preserve original test/set names.
- **Schema (app/schemas.py)**: Updated `QuestionBase`, `QuestionCreate`, and `QuestionUpdate` to include `source_test_id`.
- **Scripts**:
  - `fetch_sat_questions.py` — Scrapes questions from the Bloom Academy API (20 full tests + 330+ sectional/guided sets).
  - `seed_sat_questions.py` — Transforms and inserts all scraped questions into the database with original test names intact.
  - `export_sat_to_markdown.py` — Exports all questions to organized Markdown files (single combined, by skill, by test).
  - `add_source_test_id_column.py` — Helper to add the DB column directly.

## Seeded Data

- **6,345 unique SAT questions** inserted into the database.
- Covers **32 skills** including RW (Words in Context, Boundaries, Rhetorical Synthesis, etc.) and Math (Linear Equations, Geometry, Statistics, etc.).
- Test names preserved exactly as scraped: `fullmock-0` through `fullmock-19`, `ps-boundaries-1` through `ps-words-in-context-30`, `guided-word-in-context`, etc.
